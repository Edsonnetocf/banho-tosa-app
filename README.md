# Banho & Tosa App

## Descrição da aplicação

Aplicativo mobile voltado para petshops de pequeno e médio porte, com foco na gestão de agendamentos de banho e tosa e no cadastro de clientes e seus respectivos animais de estimação.

## Problema que a aplicação resolve

Muitos petshops de pequeno porte ainda organizam seus agendamentos manualmente (papel, planilhas ou WhatsApp), o que gera conflitos de horário, perda de histórico de atendimento dos animais e dificuldade em notificar os clientes. O Banho & Tosa App centraliza o cadastro de clientes e pets e organiza a agenda diária de forma simples e visual, evitando choques de horário e mantendo um histórico acessível de cada animal atendido.

## Tecnologias utilizadas

- **Flutter** (Dart)

**Justificativa técnica:** o Flutter foi escolhido por permitir o desenvolvimento de uma interface única para múltiplas plataformas (Android e, futuramente, iOS) a partir de uma única base de código, reduzindo o tempo de desenvolvimento. Além disso, o framework oferece suporte nativo a hot reload (o que agiliza o ciclo de testes durante as etapas incrementais da disciplina), um ecossistema maduro de pacotes para persistência local, notificações e consumo de APIs, e documentação oficial extensa, o que facilita a curva de aprendizado ao longo do semestre.

## Instruções para execução

1. Certifique-se de ter o Flutter SDK instalado e configurado (`flutter doctor` sem erros críticos).
2. Clone este repositório.
3. Navegue até a pasta do código-fonte: `cd src`
4. Instale as dependências: `flutter pub get`
5. Execute o aplicativo em um emulador ou dispositivo conectado: `flutter run`
